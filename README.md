## Abnormal Sitting Posture Recognition:

Abnormal sitting posture recognition is a system which
is designed for monitoring and triggering alerts concerning
improper posture in real time. 

Steps:

1. Heatmap processing
2. Keypoint Detection
3. Thresholding
4. Skeletal Dataset Generation
5. Feature extraction
6. Binary Classification
